# Cintamani

*Capture Everything. Connect Ideas. Discover More.*

---

## Filosofi: Permata Pengabul Harapan
Cintamani (atau Chintamani) adalah istilah dari bahasa Sanskerta yang berarti "permata pengabul harapan" (*wish-fulfilling jewel*). Dalam tradisi kebijaksanaan kuno, ini bukanlah sebuah objek material yang hanya dibanggakan, tetapi representasi dari kemampuan manusia untuk mengubah niat, kejelasan, dan mimpi menjadi realitas. Cintamani berfungsi seperti jendela yang menyatukan pengalaman hidup, ide, dan refleksi ke dalam satu sistem memori yang hidup.

Di era kebisingan digital saat ini, pikiran kita sering kali berkabut dan terfragmentasi. Ide cemerlang, pertanyaan kritis, dan kekhawatiran sejenak sering kali menguap begitu saja. **Cintamani** diciptakan untuk menangkap jejak-jejak yang paling cepat menghilang itu: satu pikiran singkat saat menunggu lampu merah, satu pertanyaan penting sebelum tidur, satu insight yang muncul saat mandi, atau satu khawatir yang tiba-tiba membanjiri. Semua itu bukan sekadar catatan; ini adalah bahan bakar bagi kebijaksanaan yang tumbuh.

## Bagaimana Ekosistem Ini Mengubah Hidup Anda?

Cintamani bekerja melalui dua fase yang sangat mulus: **Menangkap (Capture)** dan **Mengeksplorasi (Discover)**.

### 1. Zero-Friction Capture (via Cintamani Android)
Berapa banyak ide brilian yang hilang karena Anda malas membuka aplikasi pencatat, membuat judul, memilih folder, dan menambahkan tag?

Dengan aplikasi pendamping **Cintamani Android**, proses mencatat kembali ke esensinya. Aplikasi ini hanya memiliki satu kotak teks dan sebuah tombol simpan.

- **Micro-Notes Instan:** Sedang macet di jalan dan teringat solusi untuk masalah di kantor? Buka aplikasi, ketik satu kalimat, tekan Simpan. Selesai dalam 3 detik.
- **Voice-to-Text:** Tangan sedang kotor atau sedang menyetir? Tekan tombol Voice, bicaralah, dan sistem akan mengubahnya menjadi teks sekaligus merekam dinamika suara Anda (apakah Anda terdengar terburu-buru, cemas, atau antusias).
- **Ruang Aman Bebas Sensor:** Karena data ini 100% offline dan tidak ada tombol "Share to Social Media", Anda bisa jujur pada diri sendiri. Buang semua keluhan, renungan, dan ide paling mentah tanpa takut dievaluasi oleh algoritma.

### 2. Manajemen & Analisis (via Cintamani Server)
Saat Anda terhubung ke jaringan rumah, tekan tombol *Sync*. Ratusan *micro-notes* tersebut akan masuk ke **Cintamani Server** (repositori ini). Di sinilah keajaiban terjadi. Server ini tidak hanya menata data Anda; ia mengubahnya menjadi jaringan pemikiran yang bisa dijelajahi, dianalisis, dan dihubungkan secara semantik.

## 8 Mesin Analisis Kognitif: Asisten Pemikir Pribadi Anda

Mengapa Anda sangat membutuhkan fitur ini? Karena sering kali, kita terlalu sibuk menjalani hidup sehingga gagal melihat pola besar dari pikiran kita sendiri. Cintamani menggunakan AI lokal atau provider yang Anda pilih untuk menelusuri, mengkategorikan, dan menafsirkan jejak mental Anda dengan cara yang tajam dan manusiawi.

1. **Vector Embedder (Pustakawan Semantik):** Mengubah kata-kata Anda menjadi peta matematis. Ia tahu bahwa catatan Anda tentang "kelelahan bekerja" dan "ingin liburan ke pantai" saling berhubungan melalui emosi, kebutuhan, dan konteks.
2. **Intellectual DNA (Pemindai Minat Sejati):** Menjawab pertanyaan: *"Sebenarnya apa yang paling saya pedulikan bulan ini?"* Mesin ini memetakan persentase minat dan ritme energi Anda (berdasarkan frekuensi, konteks, dan perubahan waktu).
3. **Thought Evolution (Pelacak Pertumbuhan):** Pernahkah Anda merasa tidak berkembang? Mesin ini membuktikan sebaliknya. Ia merangkai catatan mentah Anda dari tahun lalu hingga hari ini, menunjukkan pola kebiasaan, perubahan prioritas, dan titik-titik pertumbuhan yang mungkin luput.
4. **Serendipity Engine (Sang Penemu Koneksi):** Sering kali, jawaban dari masalah hari ini sudah Anda pikirkan 6 bulan lalu. Mesin ini mencari pemikiran-pemikiran Anda yang berjauhan waktunya, lalu menghubungkannya ke pola pengambilan keputusan yang lebih besar.
5. **Idea Collision (Pemicu Inovasi):** Mendesak Anda berpikir *out-of-the-box* dengan membenturkan dua ide Anda yang saling tidak berhubungan. Bagaimana jika hobi berkebun Anda digabungkan dengan kebutuhan bisnis Anda? Mesin ini membuat Anda terkejut oleh kreativitas yang mungkin tak pernah Anda sadari.
6. **Blind Spot & Assumption Detector (Kritikus Realitas):** Fitur paling menyelamatkan hidup. AI akan membaca rencana dan keluhan Anda, lalu menunjukkan dengan tajam apa yang *luput* Anda pikirkan, asumsi yang tidak teruji, dan risiko yang kemungkinan besar Anda abaikan.
7. **Project Seed Generator (Katalis Tindakan):** Mengubah puluhan catatan acak, keluhan, dan harapan Anda menjadi satu dokumen *Blueprint* Proyek yang terstruktur dan siap dieksekusi. Anda tidak akan lagi kehilangan momentum karena ide terpecah-pecah.
8. **Task Extractor (Pembersih Beban Mental):** Memindai ribuan renungan filosofis Anda dan mengekstrak niat tindakan tersembunyi (misal: *"kayaknya besok harus cek oli motor"*) menjadi daftar *Action Items* yang bisa dijalankan tanpa beban otak ekstra.

## Keunggulan Arsitektur & Privasi

- **100% Privacy Absolute:** Semua data disimpan di satu file `cintamani_brain.duckdb` di komputer Anda. LLM bisa dijalankan sepenuhnya secara lokal menggunakan Ollama. Tidak ada data yang terbang ke cloud tanpa izin Anda.
- **Portabilitas 1-Folder (Zero-Build):** Berbeda dengan aplikasi modern yang rumit, sisi server ini **tidak membutuhkan instalasi Node.js, `npm`, atau *build tools***. Web UI dibangun menggunakan Vue dan dijalankan langsung tanpa proses build yang memakan waktu.
- **Antarmuka Cognitive Neo-Brutalism:** Desain *dashboard* yang tegas, solid, dan membumi (dengan 4 palet tema siap pakai). Sangat nyaman di mata untuk sesi berpikir mendalam.

## Panduan Instalasi & Penggunaan (Getting Started)

### 1. Prasyarat Sistem
- **Python 3.10** atau lebih baru.
- **Ollama** terinstal dan berjalan di sistem Anda (unduh di [ollama.com](https://ollama.com/)).
- Unduh (pull) model AI yang digunakan secara default dengan menjalankan perintah ini di terminal:

  ```bash
  ollama run qwen2.5:7b           # Model LLM untuk analisis logika
  ollama pull nomic-embed-text    # Model embedding untuk pencarian semantik
  ```
- Atau jika ingin menggunakan provider LLM komersial bisa di seting lewat Web UI atau
```bash
# Contoh Pakai DeepSeek
python manage_token.py --set-provider openai_compatible \
  --set-llm-url https://api.deepseek.com/v1 --set-api-key sk-xxx \
  --set-ollama-model deepseek-chat
python manage_token.py --set-embedding-provider openai_compatible \
  --set-embedding-model text-embedding-3-small
python reembed.py
```


### 2. Instalasi Repositori

Lakukan clone repositori ini dan masuk ke direktori server:

```bash
git clone https://github.com/tonshans/cintamani.git
cd cintamani
```

Buat *Virtual Environment* dan instal semua dependensi ringan:

```bash
python -m venv venv

# Untuk Linux / macOS:
source venv/bin/activate
# Untuk Windows:
venv\Scripts\activate

pip install -r requirements.txt
```

### 3. Generate API Token

Untuk menghubungkan aplikasi ponsel *Cintamani Android* ke Home Server ini dengan aman, Anda membutuhkan *API Token*. Generate token secara otomatis dengan perintah:

```bash
python manage_token.py --generate
```

*Sistem akan membuat file konfigurasi dan mencetak token unik di layar. Masukkan token ini ke halaman Settings di aplikasi Android Anda.*

### 4. Menjalankan Server & Web UI

Nyalakan server mesin intelijen Anda:

```bash
python run.py
```

Server API sekarang berjalan di `http://0.0.0.0:3000`.
Untuk masuk ke **Web Dashboard Eksplorasi**, buka browser di komputer Anda dan kunjungi:
**`http://localhost:3000`**

## Menjelajahi Pikiran Anda di Web Dashboard

Setelah Anda memiliki catatan (baik hasil *Sync* dari Android maupun input manual dari form di web), mulailah bereksplorasi:

1. **Global Time Machine:** Di sudut atas UI, pilih jendela waktu (*Last 30 Days*, *This Year*). AI akan memfokuskan analisisnya hanya pada memori di masa tersebut.
2. **Jalankan Eksplorasi (Sidebar):** Pilih salah satu dari 8 plugin aktif di menu kiri (misalnya: *Blind Spot Detector*).
3. **The Feedback Loop:** Saat AI menyajikan *Insight*, jangan hanya dibaca. Tekan **[ TERIMA ]** jika logikanya valid agar sistem mempelajarinya, atau **[ TOLAK ]** jika ia salah menebak.
4. **Jejak Audit (Provenance):** AI Cintamani tidak pernah berhalusinasi dari udara kosong. Di bawah setiap analisis, klik "Sumber Catatan" untuk membaca kembali teks *micro-notes* mentah yang Anda kirimkan.
5. **Thought Constellation:** Buka tab navigasi Graf untuk melihat jaring-jaring pemikiran Anda yang divisualisasikan menjadi rasi bintang interaktif.
